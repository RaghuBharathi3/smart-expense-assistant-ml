# Trained Model Artifacts

This directory stores the serialized machine learning artifacts generated by `src/train.py`.

## Files

- `expense_model.pkl`: Best-performing trained scikit-learn classifier (`LinearSVC`, selected based on held-out test weighted F1-score and accuracy).
- `vectorizer.pkl`: Fitted `TfidfVectorizer` (`ngram_range=(1, 2)`, `min_df=2`, `sublinear_tf=True`) fit strictly on the training split.
- `model_metadata.json`: Evaluation metrics, confusion matrices, dataset split sizes, and class labels from the latest training run.

## Regenerating Artifacts

```bash
python -m src.train
```
